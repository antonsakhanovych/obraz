# Obraz

**Obraz** is a personal framework for articulating the complete inner form of a person. From Russian образ, not a portrait but the full truth.

It is structured around six sections: Signal, Problems, Maxims, Frequency, Contradictions, and Projects. Each section has core questions that ensure the essential things get answered. Beyond that it is open. If something is true about you and fits the section, it belongs there. You do not need a question to authorize it.

See [MANIFESTO.md](./MANIFESTO.md) for the framework.
